# File Management System (Dosya Yönetim Sistemi)

Spring Boot ve React kullanılarak geliştirilen, kullanıcıların dosya ve klasörlerini
yönetebileceği web tabanlı bir dosya yönetim sistemi.

## Özellikler

- Kullanıcı girişi ve yetkilendirme (JWT)
- Klasör oluşturma, dosya yükleme/indirme/silme/taşıma
- Kullanıcıya özel ve link ile dosya paylaşımı
- Admin paneli (kullanıcı yönetimi, tüm dosyaları görüntüleme)
- Dosya arama
- Soft delete (çöp kutusu)

## Teknolojiler

**Backend:** Java, Spring Boot, Spring Data JPA, Spring Security, JWT, PostgreSQL

**Frontend:** React, Material UI, Axios

## Proje Yapısı

```
file-management-system/
├── backend/     # Spring Boot API
├── frontend/    # React uygulaması
└── docs/        # ER diyagramı, API dokümantasyonu, gereksinim analizi
```
